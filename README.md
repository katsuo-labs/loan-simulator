# 住宅ローン金利シミュレーター

変動金利の将来シナリオを自分で設定して、全期間固定型と毎月の返済額・総返済額を比較できる無料ツールです。

**▶ 使ってみる: https://katsuo-labs.github.io/loan-simulator/**

## 特徴

- 変動金利の上昇シナリオを「〜西暦◯年◯月まで◯%」形式で自由に設定し、固定金利と並列比較
- **5年ルール・125%ルール**（返済額の据え置きと1.25倍上限）を正確に計算。未払利息の発生や完済時の残債も検出して警告
- 繰上返済（期間短縮型・返済額軽減型）対応。変動・固定の両方に同条件で適用して公平に比較
- 物件価格・頭金から借入額を自動計算。元利均等・元金均等の両方式に対応
- 金利シナリオを複数プランとして保存し、表で並べて比較
- 入力データはブラウザ内（localStorage）にのみ保存。サーバー送信なし。JSONでバックアップ・復元可能
